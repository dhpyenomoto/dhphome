# images — 写真の格納庫 / Photo storage

各プロジェクトのギャラリー写真を置くフォルダです。
Stores gallery photos for each project.

## 追加方法 / How to add

### A. 管理画面からアップロード（推奨・iPad対応）
1. `admin.html` を開き、対象プロジェクトを「編集」。
2. 「写真」セクションの **「写真を選択」** から端末・iPad の写真を選ぶ
   （またはドラッグ＆ドロップ）。
3. 「GitHub に保存」パネルの **リポジトリ／ブランチ／トークン（PAT）** を使って、
   画像がこの `images/` フォルダに自動コミットされ、ギャラリーに登録されます。
   - 既定で長辺2000pxへ縮小して軽量化します（チェックで切替）。
4. 続けて「GitHub に保存」で `data.js` も保存すると、写真の紐付けが確定します。

### B. URL / Dropbox を登録
- 画像の直URL、または **Dropbox の共有リンク**（自動で直接表示用URLに変換）を
  「URLで追加」で登録できます。この場合ファイルはリポジトリに置きません。

### C. 手動
- このフォルダに画像を直接コミットし、admin で `images/ファイル名` を登録。

## メモ
- 静的サイトのため、アップロード＝GitHub へのコミットです（PATが必要）。
- ファイル名は自動で `プロジェクトID-日時-ランダム-元名.jpg` に整えられます。
